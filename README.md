## 🚀 About Me

Hey! I’m **Rafli**, an **Independent Blockchain & Web3 Developer** who enjoys building things that actually run — not just reading docs.

I work across **smart contracts, backend APIs, and modern frontends**, with hands-on experience experimenting with multiple blockchain stacks.  
My current focus is understanding **how decentralized systems work end-to-end** — from contract logic and testing, to frontend interaction and infra tooling.

I believe in:
- learning by shipping,
- breaking things on testnets,
- and growing through real projects instead of hype.

## 🧠 Current Focus

- ⚙️ Building and testing smart contracts using **Hardhat** & **Foundry**
- 🔐 Exploring **Zero-Knowledge (ZK)** concepts and practical use cases
- 🧩 Experimenting with **Sui Move** as an alternative smart contract model
- 🌐 Connecting contracts to frontend apps using **viem**
