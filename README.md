## 🚀 About Me

Hey there! I'm **Rafli**, an **Independent Web3 Developer** passionate about building decentralized applications and exploring the next frontier of the internet.  
Currently diving deep into **SUI**, **Move**, and **zkLogin** — while experimenting with modern tools that bring real utility to Web3.

Even though I’ve just started my journey in the blockchain space, I’m already hands-on with projects like **ARO Testnet** and **SUI Dapp experiments**, learning fast and sharing insights along the way.
